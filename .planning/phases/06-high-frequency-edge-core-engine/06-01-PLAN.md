# Phase 6 Plan 01: Standalone High-Frequency Edge Core Engine & 200 Hz Streaming Benchmark

## Objective

- **What:** Modularize the Intelligent Dead Reckoning and Kalman Fusion navigation core into a standalone, headless edge engine supporting up to 200 Hz IMU rates with C FFI bindings and zero UI dependencies.
- **Why:** Meets SIH requirements EDGE-01 and EDGE-02, enabling low-latency deployment on vehicle edge computing units (Jetson, Raspberry Pi, industrial IPCs) and tactical/FOG IMUs.
- **Output:** `src/edge/` package with C-ABI interface, high-throughput ring buffer, multi-rate 200 Hz navigation runner, C header `include/idr_edge_engine.h`, test suite `tests/test_phase6.py`, and evaluation benchmark `evaluate_phase6.py`.
