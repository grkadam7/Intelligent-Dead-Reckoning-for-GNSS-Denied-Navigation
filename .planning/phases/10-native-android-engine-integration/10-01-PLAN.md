# 10-01 — Build, package and bind the native engine

<objective>
Make `libidr_mobile.so` a real part of the Android release APK and give Dart a safe way to call its C ABI. This plan ends with a green CI build whose APK demonstrably contains the native library; engine selection and DR parity are in plan 02.
</objective>

<context>
Read 10-CONTEXT.md, Phase 10 in ROADMAP, NENG-01, native/include/idr_mobile.h, native/CMakeLists.txt, mobile/lib/navigation/native_source.dart and .github/workflows/build_apk.yml. Critical: CI deletes and regenerates `mobile/android` on every run, so Gradle changes must be injected by the workflow, not committed under `mobile/android`. This machine has no g++/cmake/Android SDK; CI is the only place the .so can be built and inspected.
</context>
